# Selected research sources

These are curated snapshots of the strongest source repositories across six researched domains. They retain skill/workflow instructions, supporting references/assets, research-cited files, and minimal root README/license/notice files. Tests, CI, unrelated applications, generated output, dependencies, and unlinked media are omitted.

The selection keeps the three highest-ranked distinct repositories per domain. Some repositories serve multiple domains, so 14 unique repositories cover 18 domain slots:

| Domain | Selected repositories |
|---|---|
| Security | Natolitech/security-skill, Semgrep/skills, Olanokhin/agent-security-skill |
| Backend | Addy Osmani/agent-skills, Alireza Rezvani/claude-skills, Jeffallan/claude-skills |
| Database | Supabase/agent-skills, Alireza Rezvani/claude-skills, Ccheney/robust-skills |
| Testing | Obra/superpowers, Bambu-Developers/skills, Mthines/agent-skills |
| SDLC process | GitHub/spec-kit, Addy Osmani/agent-skills, Obra/superpowers |
| Packaging | AgentSkills/agentskills, Pulumi/agent-skills, Addy Osmani/agent-skills |

These are ordinary files that can be browsed directly on GitHub. Upstream Git history and unselected repositories are not included. Snapshots are not automatically updated; review changes and regenerate the curated files when refreshing them.
