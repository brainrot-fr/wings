# Question Protocols
- One question at a time is common when a workflow wants to preserve context and reduce drift. [V] README and skill docs.
- Batched prompts are used in high-level planning and summary tasks. [V] repo docs.
- Open prompts are paired with assumption or decision markers when uncertainty is being handled. [V] repo docs.
- Stop rules usually tie to validation, convergence, or review completion. [V] repo docs.
